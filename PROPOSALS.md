# Предложения по развитию продукта

Ниже — идеи, которые не входили в требования тестового задания, но кажутся логичным следующим шагом
для реального продукта на базе этого SPA. Сгруппированы по соотношению эффект/усилия, чтобы было проще
расставить приоритеты. Ни одна из идей не реализована в текущей версии — это предложения на обсуждение.

## Quick wins (малый эффорт, заметный эффект)

- **Тёмная тема.** Дизайн-система уже построена на токенах Tailwind (палитра, тени, радиусы вынесены
  централизованно) — добавить `dark:`-варианты и переключатель можно относительно быстро, без переписывания
  компонентов.
- **Избранное (Favorites).** Звёздочка на карточке аукциона + отдельный фильтр «только избранное».
  Хранить можно локально (localStorage), как и текущие фильтры — бэкенд не нужен для MVP.
- **Сохранённые пресеты фильтров.** Пользователь настраивает фильтры один раз (например, «мои города +
  доступные для ставки») и сохраняет под именем, чтобы не собирать заново каждый раз. Тоже реализуемо
  через localStorage без бэкенда.
- **Расширение e2e-покрытия.** Сейчас покрыты ключевые сценарии (список, фильтры, детальная, ставка).
  Можно добавить: пагинацию на границах (последняя/первая страница), одновременную установку ставки
  двумя вкладками, edge-case с `422` от сервера.

## Вовлечённость пользователя (Engagement)

- **Реалтайм-обновление торгов (WebSocket/SSE).** Сейчас цена/статус обновляются через инвалидацию
  TanStack Query после действий текущего пользователя. В реальных торгах цена может меняться от действий
  других участников — стоит показывать это live, без ручного refresh.
- **Push/browser-уведомления.** Уведомлять, если пользователя перебили ставкой на аукционе, где он
  участвует (Losing), или если торги, где он лидирует (Leading), подходят к завершению.
- **Оптимистичные обновления (optimistic updates).** При установке ставки — мгновенно показывать
  ожидаемое состояние в UI, откатывая при ошибке сервера, вместо ожидания round-trip перед обновлением
  интерфейса.

## Продуктивность и масштаб (Scale/Productivity)

- **Карта маршрута.** Визуализация точек погрузки/выгрузки на карте (например, Leaflet/MapBox) —
  особенно полезно на детальной странице, где сейчас маршрут только текстом.
- **Сравнение аукционов.** Возможность отметить несколько карточек и открыть их side-by-side для
  сравнения условий (цена, груз, маршрут, дедлайны).
- **Массовая установка ставок (bulk bidding).** Для активных участников торгов — установить ставку сразу
  на несколько отфильтрованных аукционов одним действием (с подтверждением каждой).
- **Виртуализация / infinite scroll списка.** При больших объёмах данных постраничная навигация не всегда
  удобна — виртуализированный список с подгрузкой по скроллу может быть лучше для частых пользователей.

## Инфраструктура и качество (Infrastructure/Quality)

- **PWA.** Манифест + service worker для офлайн-доступа к последнему загруженному списку и установки
  приложения на устройство — актуально для водителей/логистов, работающих в дороге с нестабильной сетью.
- **Аналитика использования.** Трекинг ключевых событий (открытие фильтров, установка ставки, переходы
  на детальную) для понимания, какие сценарии реально используются и где отваливаются пользователи.
- **Интернационализация (i18n).** Сейчас весь текст захардкожен на русском — вынос строк в отдельный
  слой переводов упростит выход на другие рынки без переписывания компонентов.
